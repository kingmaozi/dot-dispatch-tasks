# 派工账本（Dispatch Ledger）

本仓库只存**派工 issue**，是任务真源。代码不在这里。

## 为什么要单独一个公开仓

任务真源必须是云端能**匿名读到**的地方。私有的主仓在访问上不稳，
一旦云端读不到 issue，任务就只剩一句含糊的对话，很容易做偏。

这里放公开仓，只放任务描述、边界和验收标准，**不放业务代码、不放凭据**。

## 一条 issue 必须写清五件事

| 项 | 要求 |
| --- | --- |
| 任务号 | 唯一，写进每条 Slack 消息的身份头 |
| 目标 | 一句话说清要解决什么问题 |
| 基线 | **40 位完整 commit SHA**（`git rev-parse HEAD`）。短 SHA 会歧义 |
| 允许改的文件 | **穷举**清单。说「相关文件」等于没说 |
| 验收 | 可直接复制运行的命令 + 预期退出码 |

外加**禁止事项**（不推送、不合并、不发布、不删数据）。

## 回执格式

云端完成时在本 issue 对应的 Slack 线程里回复，开头复述身份头，结尾单独一行：

```
END TASK=<任务号>
```

**没写这行就不算完成**，主会话会继续追问。
